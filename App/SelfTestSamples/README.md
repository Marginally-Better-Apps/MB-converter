# Self-test samples

Real files bundled with the app so **Settings → Diagnostics → Self-Test** can exercise every tool on the device itself (Vision, hardware encoders and other features the simulator can't run). The same files back the CI test suite.

| File | Source / license |
| --- | --- |
| `astronaut-portrait.jpg` | NASA photo S69-31741 (Neil Armstrong), public domain; 500 px thumbnail via Wikimedia Commons. Used for face blurring and background removal. |
| `usgs-streamstats.pdf` | USGS Fact Sheet 2017-3046, public domain. CMYK JPEG 2000 photos and maps. |
| `irs-w4-form.pdf` | IRS Form W-4, public domain. Fillable AcroForm. |
| `test-pattern.mp4` | Generated with FFmpeg `testsrc2` + sine tone; no third-party content. |
| `sample.*` | Small Word, OpenDocument, PowerPoint, Excel and RTF files made for this project. |
